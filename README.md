Student Management System

About the Project

The Student Management System is a web-based application developed to manage student information efficiently.

Technologies Used

- React.js
- Vite
- JavaScript
- CSS
- HTML

Project Features

- Student information management
- User-friendly interface
- Organized project structure

Installation and Setup

1. Clone the repository:
   
   git clone https://github.com/ShreyaSanganwar/Student-Management-System.git

2. Open the project folder.

3. Install dependencies:
   
   npm install

4. Start the project:
   
   npm run dev
